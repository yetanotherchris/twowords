
# TwoWords Data

This directory contains the data sources and word lists used by the TwoWords API.

## Current Status

The live word list is **v2** in `words/v2/`. It contains exactly **64,434 words** — one per
longitude bin of the central-UK grid — so every valid coordinate maps to a unique `word1.word2`
pair. The shipped ordering is `words/v2/curated-by-chris-words-conurb-prioritized.txt`, copied
verbatim to `/words.txt` and `/src/TwoWordsApi/words.txt` (the file the API actually reads).

See `words/v2/README.md` for the v2 pipeline, file roles, and how to regenerate the list.

Words are drawn from multiple sources (Norvig, WordNet, Kaggle common words, food dishes,
conversational/tech terms) and filtered to 3–8 letter, lowercase, vowel-containing words with
stop words, city names, profanity, acronyms, plurals, and inflected forms removed.

## Layout

- `words/v2/` — **current** 64,434-word list, build/prioritization scripts, and conurbation files.
- `words/v1/` — earlier source tree and experiments (Norvig, WordNet, cities, first names, Kaggle,
  Claude-curated lists). v2's `build_64434.py` still reads its raw sources from here.
- `history.md` — the full evolution of data sources and curation methods.

## Notes

The list was generated by scripts and then hand-finalised, so `words/v2/curated-by-chris-words.txt`
is committed as the source of truth rather than regenerated on every build. Geographic filtering and
coordinate mapping are handled by the API itself using the polygon data (`central-uk.json`).
