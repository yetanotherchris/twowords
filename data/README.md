# TwoWords Data Pipeline - Python Tools

## Overview
This directory contains the Python scripts and utilities used to generate, curate, and filter the word lists for the TwoWords API. The pipeline ensures that the final word list is optimized for memorable, high-quality, and geographically relevant word pairs for the UK and Ireland.

## Running the Pipeline

### Using Docker (Recommended)

The easiest way to run the data pipeline is using Docker:

```bash
# Build the Python CLI image
docker build -f data/Dockerfile -t twowords-data .

mkdir -p data/output

# Show the correct order of steps
docker run --rm twowords-data steps

# Run the complete pipeline in order:
docker run --rm -v $(pwd)/data/output:/output twowords-data download-polygon
docker run --rm -v $(pwd)/data/output:/output twowords-data popular
docker run --rm -v $(pwd)/data/output:/output twowords-data filter
docker run --rm -v $(pwd)/data/output:/output twowords-data calculate-indices
docker run --rm -v $(pwd)/data/output:/output twowords-data optimize
docker run --rm -v $(pwd)/data/output:/output twowords-data verify
docker run --rm -v $(pwd)/data/output:/output twowords-data zip

# All output files will be written to your local data/output directory
```

### Using Python directly

If you have Python 3.11+ and the required dependencies installed:

```bash
cd data/python
pip install -r requirements.txt

# Show the correct order of steps
python twowords_cli.py steps

# Run the complete pipeline in order:
python twowords_cli.py download-polygon
python twowords_cli.py popular
python twowords_cli.py filter
python twowords_cli.py calculate-indices
python twowords_cli.py optimize
python twowords_cli.py verify
python twowords_cli.py zip
```

## CLI Usage
The main entry point for most operations is the CLI script:

```bash
python twowords_cli.py [command] [options]
```


### Available Commands
- `curate` — Generate curated list of words from multiple sources
- `filter` — Filter words for polygon (mark out-of-bounds indices)
- `zip` — Generate words.zip from output/words.txt
- `download-polygon` — Download or refresh the polygon zip file

Each command has its own options and help. Run `python twowords_cli.py --help` for details.

## Pipeline Steps

### 1. Word List Generation

#### Sources Used
- **Peter Norvig's Curated English Word List** (`data/words/norvig-word-list.txt`)
  - URL: https://norvig.com/ngrams/word.list
  - 263,533 high-quality English words, manually curated
  - Not used anymore, but was used to begin with.
- **Common Nouns** (`data/words/common_nouns.txt`)
  - Derived from the Kaggle frequency lists.
- **Food Dishes** (`data/words/food_dishes_final.txt`)
  - 163 food terms, manually curated by Chat GPT.
- **Common Words** (`data/words/common_words.txt`)
  - Initially generated by ChatGPT, then manually reviewed
- **WordNet** (via NLTK)
  - Used for additional noun extraction and validation
- **Kaggle Ngram Frequency** (`data/words/kaggle-extracted/ngram_freq.csv`)
  - Used for frequency-based filtering

#### Attribution
- **ChatGPT**: The initial `common_words.txt` was generated by ChatGPT and then manually reviewed for quality.
- **Peter Norvig**: The Norvig word list is the main curated source, even if not all words are used in the final output.
- **WordNet**: Used for additional noun extraction.
- **Kaggle**: Provided frequency data for further filtering (https://www.kaggle.com/datasets/wheelercode/english-word-frequency-list).

#### Generation Process
- The main script for initial list creation is `words_create_inital_curated_list.py`, which uses utilities in `twowords_utils/word_curation.py` to merge, deduplicate, and filter words from all sources.
- Words are filtered for length, character set, and appropriateness.
- Food dishes and common words are prioritized for memorability.
- The CLI `curate` command handles this process through the WordCurator class.

### 2. Geographic Filtering

- The script `words_filter_for_polygon.py` and CLI `filter` command use a UK/Ireland polygon (`polygons/uk_polygon.wkt.zip`) to filter out words that would map to coordinates outside land areas.
- The filtering ensures that only grid cells within the UK/Ireland landmass are assigned words.
- Utilities in `twowords_utils/polygon_utils.py` handle polygon loading and point-in-polygon checks.


### 3. Word List Generation and Output

- Word curation and filtering are handled by the CLI commands `curate` and `filter`.
- The `curate` command uses the WordCurator class to merge and filter words from multiple sources.
- The `filter` command applies geographic filtering to ensure words only map to valid land coordinates.
- The `zip` command creates a compressed words.zip file from the final word list.
- The final output is written to `data/output/words.txt`.



### 4. Pipeline Management

- The pipeline is designed to be deterministic and stateless: the same coordinates always yield the same word pair.
- The CLI provides commands for downloading polygon data and creating compressed outputs.
- All operations can be performed through the `twowords_cli.py` script.

## File Overview
- `twowords_cli.py` — Main CLI entry point with commands: curate, filter, zip, download-polygon
- `words_create_inital_curated_list.py` — Legacy script for initial word list generation (now handled by CLI)
- `words_filter_for_polygon.py` — Legacy script for polygon filtering (now handled by CLI)
- `twowords_utils/` — Utility modules for word curation, polygon handling, and zip management

## Data Files
- `output/words.txt` — Final curated word list
- `words/norvig-word-list.txt` — Peter Norvig's curated English words
- `words/common_nouns.txt` — Common nouns
- `words/food_dishes_final.txt` — Food dishes
- `words/common_words.txt` — Common words (ChatGPT-generated)
- `words/important_indices.txt` — Population centre indices
- `words/optimized_words_sorted_by_score.txt` — Pre-scored word list
- `polygons/uk_polygon.wkt.zip` — UK/Ireland land polygon
- `kaggle-extracted/ngram_freq.csv` — Word frequency data

## Notes
- All scripts are designed for reproducibility and transparency.
- The pipeline is stateless and does not require a database.
- All sources are attributed above, including unused or fallback sources.
