# TwoWords Data Pipeline - Python Tools

## Overview
This directory contains the Python scripts and utilities used to generate, curate, and filter the word lists for the TwoWords API. The pipeline ensures that the final word list is optimized for memorable, high-quality, and geographically relevant word pairs for the UK and Ireland.

## CLI Usage
The main entry point for most operations is the CLI script:

```bash
python twowords_cli.py [command] [options]
```

### Available Commands
- `generate_initial_list` — Create the initial curated word list from multiple sources.
- `filter_for_polygon` — Filter words by UK/Ireland land polygon.
- `optimize_word_list` — Score and optimize the word list for memorability and population centers.
- `calculate_popular_indices` — Calculate grid indices for major UK/Ireland cities.
- `verify_indices` — Check mapping correctness for specific coordinates/indices.

Each command has its own options and help. Run `python twowords_cli.py --help` for details.

## Pipeline Steps

### 1. Word List Generation

#### Sources Used
- **Peter Norvig's Curated English Word List** (`data/words/norvig-word-list.txt`)
  - URL: https://norvig.com/ngrams/word.list
  - 263,533 high-quality English words, manually curated
  - Used as the primary source for filtering and validation
- **Common Nouns** (`data/words/common_nouns.txt`)
  - Derived from various open datasets and frequency lists
- **Food Dishes** (`data/words/food_dishes_final.txt`)
  - 163 food terms, manually curated for memorability
- **Common Words** (`data/words/common_words.txt`)
  - Initially generated by ChatGPT, then manually reviewed
- **WordNet** (via NLTK)
  - Used for additional noun extraction and validation
- **Kaggle Ngram Frequency** (`data/words/kaggle-extracted/ngram_freq.csv`)
  - Used for frequency-based filtering

#### Attribution
- **ChatGPT**: The initial `common_words.txt` was generated by ChatGPT and then manually reviewed for quality.
- **Peter Norvig**: The Norvig word list is the main curated source, even if not all words are used in the final output.
- **WordNet**: Used for additional noun extraction.
- **Kaggle**: Provided frequency data for further filtering.

#### Generation Process
- Scripts like `words_create_inital_curated_list.py` and utilities in `twowords_utils/word_curation.py` merge, deduplicate, and filter words from all sources.
- Words are filtered for length, character set, and appropriateness.
- Food dishes and common words are prioritized for memorability.

### 2. Geographic Filtering

- The script `words_filter_for_polygon.py` uses a UK/Ireland polygon (`polygon/uk_polygon.wkt.zip`) to filter out words that would map to coordinates outside land areas.
- The filtering ensures that only grid cells within the UK/Ireland landmass are assigned words.
- Utilities in `twowords_utils/polygon_utils.py` handle polygon loading and point-in-polygon checks.

### 3. Word List Optimization

- The script `optimize_word_list.py` scores words based on:
  - Food dish status (+60 points)
  - Shortness (≤3 chars, +50 points)
  - Commonality (+40 points)
  - Simplicity of letter patterns (+20 points)
- Population center indices (from `important_indices.txt`) are assigned the most memorable words.
- The final output is written to `data/output/words.txt` (110,001 entries).

### 4. Validation and Testing

- `verify_indices.py` checks that specific coordinates map to the expected words.
- The pipeline is designed to be deterministic and stateless: the same coordinates always yield the same word pair.

- `words_filter_for_polygon.py` — Filters words by UK/Ireland polygon

- `kaggle-extracted/ngram_freq.csv` — Word frequency data

## Notes

- The pipeline is stateless and does not require a database.
