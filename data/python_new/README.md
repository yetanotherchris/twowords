# TwoWords Enhanced UK Cities Coverage System

This enhanced version of the TwoWords data pipeline provides comprehensive coverage for all 76 officially recognized UK cities with intelligent word placement for better user experience in populated areas.

## Overview

The system now includes:

- **Complete UK City Coverage**: All 76 cities (55 England, 8 Scotland, 7 Wales, 6 Northern Ireland)
- **Radius Expansion**: 2-mile radius coverage around each city center
- **Strategic Word Placement**: Food dishes and friendly words at populated areas
- **Enhanced Scoring**: WordNet integration for better word selection
- **Comprehensive Verification**: Multi-level validation system

## Key Features

### 1. UK Cities Coverage (`cities_best_words_for_center_point.py`)

Generates coordinate indices for all officially recognized UK cities:

- **England (55 cities)**: London, Birmingham, Leeds, Sheffield, Bradford, Liverpool, Manchester, Bristol, Newcastle upon Tyne, Nottingham, Leicester, Coventry, Hull, Plymouth, Stoke-on-Trent, Derby, Southampton, Portsmouth, York, Peterborough, Norwich, Sunderland, Oxford, Cambridge, Brighton and Hove, Exeter, Chester, Gloucester, Lancaster, Lincoln, Chichester, Worcester, Canterbury, Carlisle, Durham, Ely, Hereford, Lichfield, Ripon, Truro, Wakefield, Wells, Winchester, Salisbury, Bath, Chelmsford, Preston, Salford, Wolverhampton, Southend-on-Sea, Milton Keynes, Blackpool, Middlesbrough, Doncaster, Reading

- **Scotland (8 cities)**: Glasgow, Edinburgh, Aberdeen, Dundee, Stirling, Perth, Inverness, Elgin

- **Wales (7 cities)**: Cardiff, Swansea, Newport, Bangor, St Davids, St Asaph, Wrexham

- **Northern Ireland (6 cities)**: Belfast, Derry/Londonderry, Armagh, Lisburn, Newry, Bangor

### 2. Enhanced Word Curation (`word_curation.py`)

Improvements include:

- **Priority Food Placement**: Food dishes get highest priority at city indices
- **WordNet Integration**: Enhanced word scoring using semantic analysis
- **Large Common Words**: Support for expanded common word lists

Comprehensive verification including:

- City count validation (76 cities total)

- Food dish placement verification
- Coordinate coverage validation

## Usage

### Quick Start

```bash
# 1. Generate city indices with 2-mile radius coverage
python twowords_cli.py generate-city-indices

# 2. Curate and optimize word list
python twowords_cli.py curate-words

# 3. Verify the results
python twowords_cli.py verify
```

### Advanced Usage

```bash
# Generate city indices with custom radius
python twowords_utils/cities_best_words_for_center_point.py --radius 3.0 --verify

# Run verification separately
python twowords_utils/verify_uk_cities.py
```

### Docker Usage

```bash
# Complete pipeline
docker run --rm -v $(pwd)/data/output:/output twowords-data generate-city-indices
docker run --rm -v $(pwd)/data/output:/output twowords-data curate-words
docker run --rm -v $(pwd)/data/output:/output twowords-data verify
```

## Technical Details

### Coordinate System

- **Latitude range**: 49.0° to ~58.7° (UK bounds)
- **Longitude range**: -8.0° to ~1.8° (UK bounds)
- **Grid step**: 0.0001 degrees (~11 meters)
- **Index calculation**: `int((coord - MIN) / STEP)`

### Radius Calculation

The system generates points within a 2-mile radius using:

- **Concentric circles**: 30%, 60%, 100% of radius
- **Uniform distribution**: Square root scaling for even coverage
- **Random points**: Additional 12 random points per city
- **Haversine distance**: Accurate great-circle distance calculation

### Word Scoring Algorithm

Enhanced scoring considers:

1. **Length penalty**: Shorter words preferred (3-5 chars optimal)
2. **Food dishes**: Highest priority (+60 points)
3. **Large common words**: Second priority (+55 points)
4. **WordNet analysis**: Animals (+30), Places (+25), Nouns (+20)
5. **Simple words**: Avoid complex letter patterns (+20)
6. **Singular preference**: Avoid plurals (-8 to -15 points)
